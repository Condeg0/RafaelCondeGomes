### 🎾 BreakPoint AI — ATP Tennis Match Forecasting
**Stack:** Python · PyTorch · Optuna · Time-Series Analysis

Built a **Hybrid Siamese LSTM** network that models a tennis match as the collision of two historical momentum trajectories, rather than static player statistics. Applied strict temporal filtration (`date < current_date`) to eliminate data leakage.
